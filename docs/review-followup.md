# Implementation boundaries

The public configure page starts without an account. Install tokens use authenticated encryption, account clients and library indexes are isolated, and private request URLs are never logged by the application. Static paths are explicitly allowed; arbitrary project and data files return 404. Configuration requests have size and rate bounds. The hosting platform can log encrypted token paths; the operator must still be trusted.

Searches and HEAD playback probes do not modify a TorBox account. GET playback rechecks availability and uses `add_only_if_cached=true` when the release is not already owned. Selected video filenames and sizes are validated again before requesting the CDN link. Existing account files are reused. CDN links can expose the account key; install and playback URLs must be treated as account capabilities.

The resolver keeps known public/library results when discovery partially fails. Exact metadata-ID matches retain their verified status through title fallback merging. Unverified title matches use canonical title/year checks. Collection files are matched individually; season packs require the requested episode. Supported anime catalog mappings run before the same resolver, with explicit season/cour conversion rather than largest-file guessing.

Version 0.4 removes fixed candidate and result caps, combines ID and title searches, and uses the upstream AIOStreams parser/sorter. Audio languages are read from release attributes rather than title words; optional TMDB metadata supplies original language and title aliases. Per-account availability, negative, parser and response caches are bounded. Public discovery work can be coalesced across accounts; private cache responses cannot.

Remaining boundaries: independent-index coverage is incomplete; some AIO reference hashes remain undiscovered. Full SEL, synchronized regex rules, SeaDex, bitrate enrichment and every upstream AIO filter are not implemented. Anime mappings can be ambiguous, in which case resolution fails rather than selecting an arbitrary episode. Individual upstream timeouts can accumulate during failures. Instance caches reset on cold starts. Signed playback links expire after 24 hours.
